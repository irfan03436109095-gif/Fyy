Clash 类客户端电脑能用，手机连不上？局域网代理检查

王牌飞行员2026-09-24— 次阅读
客户端与工具

电脑上的 Clash 类客户端能正常联网，手机却无法使用电脑的代理端口，通常需要同时满足三个条件：客户端允许局域网访问、监听地址覆盖局域网网卡、系统防火墙允许相应入站连接。只打开其中一项，手机仍可能超时。

先确认电脑与手机在同一局域网

让两台设备连接同一个可信 Wi-Fi，关闭手机蜂窝数据后记录电脑的局域网 IPv4 地址。不要把 127.0.0.1 填到手机里；它在手机上指向手机自身。代理服务器地址应使用电脑在该局域网中的地址，端口则使用客户端实际显示的 HTTP、SOCKS 或混合端口。

核对 allow-lan 与监听地址

Mihomo 官方通用配置说明，allow-lan: true允许其他设备通过 Clash 代理端口访问；bind-address决定监听到哪些地址。"*"会绑定所有地址，也可以只绑定电脑的某个局域网地址。

如果图形客户端提供“允许局域网”开关，优先在界面中设置，不要同时手改配置文件和界面。启用后重新查看实际监听端口。若配置还包含 lan-allowed-ips 或 lan-disallowed-ips，确认手机地址没有被排除。

用最小请求区分端口与规则问题

在手机的 Wi-Fi 代理设置中填入电脑局域网地址和 HTTP 或混合端口，然后访问一个普通 HTTPS 页面。若立即提示无法连接，先回到电脑确认客户端正在运行、端口没有被其他程序占用。

在 Windows 可用以下命令检查端口是否监听，其中 7890替换为客户端实际端口：

netstat -ano | findstr :7890

看到只监听 127.0.0.1:7890，意味着局域网设备无法直接连接；看到 0.0.0.0:7890或电脑局域网地址，才说明监听范围可能覆盖局域网。进程和端口信息仍要与客户端界面交叉核对。

再检查 Windows 防火墙

如果监听地址正确但手机仍超时，检查 Windows 当前网络配置文件是否为预期类型，以及该客户端或端口是否允许入站。只为当前客户端和必要端口添加规则，范围限制在专用网络或可信局域网；不要为了测试关闭整个防火墙。

若弹出 Windows 安全提示，核对程序路径和发布者后再选择网络范围。公共 Wi-Fi 上不建议启用局域网代理，也不要把代理端口暴露到路由器公网转发。

验收时同时看电脑与手机

手机打开网页后，再查看电脑客户端连接记录，确认请求来自手机局域网地址并命中预期规则。随后关闭手机代理，确认网络恢复；关闭 allow-lan 后再次测试，手机应无法继续连接该端口。

如果手机能连接但访问结果异常，问题已从“端口不可达”缩小为代理类型、认证或分流规则。一次只修改一项并复测，避免把监听、防火墙和规则同时改动后无法判断是哪一步生效。
